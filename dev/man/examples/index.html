kegg_conv

These examples call the KEGG Conv operation. kegg_conv returns the request URL, column names, and data in a KeggTupleList. Construct a DataFrame from output.data and output.colnames:

output = KEGGAPI.kegg_conv("genes", "ncbi-geneid:948364")
@assert output isa KEGGAPI.KeggTupleList
DataFrame(output.data, output.colnames)
