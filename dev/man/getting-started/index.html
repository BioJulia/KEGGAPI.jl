Getting started with KEGGAPI.jl

Installation

From the Julia REPL, type ] to enter the Pkg REPL and install KEGGAPI.jl:

pkg> add KEGGAPI

Usage

Load KEGGAPI.jl with using:

Each wrapper is named after its KEGG operation. This call lists all organisms in KEGG:

result = KEGGAPI.kegg_list("genome")
@assert result isa KEGGAPI.KeggTupleList

The result contains the request URL, column names, and data:

"https://rest.kegg.jp/list/genome"

Error handling

KEGGAPI lets HTTP.jl exceptions propagate. An unsuccessful HTTP response throws HTTP.Exceptions.StatusError. Connection, request, and timeout failures throw HTTP.Exceptions.ConnectError, HTTP.Exceptions.RequestError, and HTTP.Exceptions.TimeoutError, respectively. See KEGGAPI.request for the low-level request contract.
